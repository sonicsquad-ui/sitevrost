# sitevrost.ru — диджитал-агентство «Сайт в Рост»

Многостраничный адаптивный сайт диджитал-агентства (создание и продвижение сайтов)
с блогом, кейсами и полноценной административной панелью.

- **Стек:** PHP 8.0+ (без MySQL, файловое JSON-хранилище), vanilla JS/CSS.
- **Хостинг:** любой простой shared-хостинг (REG.RU) — см. `README-DEPLOY.md`.
- **Админка:** `/admin` — визуальный редактор TinyMCE для страниц, статей и кейсов,
  заявки с форм, редактирование шапки/футера/сквозных блоков, меню, безопасности.
- **SEO:** OpenGraph + Twitter + Schema.org (JSON-LD) на всех страницах,
  хлебные крошки, `robots.txt`, автоматический `sitemap.xml`, HTML-карта сайта.
- **Формы:** обязательная галочка согласия на обработку персональных данных,
  CSRF, антиспам, дублирование заявок на почту.

Первичное наполнение (44 страницы, 10 статей, 6 кейсов) генерируется скриптом
`tools/seed.php` и далее редактируется через админку.
