# Развёртывание на хостинге REG.RU (простой shared-хостинг, без VPS)

Сайт «Сайт в Рост» — PHP + файловое хранилище JSON. **База данных MySQL не требуется.**
Работает на любом тарифе REG.RU с PHP 8.0+ (рекомендуется 8.1–8.2).

## Шаг 1. Загрузка файлов
1. В панели REG.RU откройте «Файловый менеджер» или подключитесь по FTP/SFTP.
2. Скопируйте **всё содержимое репозитория** в корневую папку домена `sitevrost.ru`
   (обычно это `public_html`, `www` или `sitevrost.ru/`).
3. Убедитесь, что папки `data/` и `upload/` существуют и доступны для записи
   (права 755 обычно достаточно; если нет — поставьте 775).

## Шаг 2. PHP
В панели хостинга («Хостинг» → «Настройки PHP») выберите версию **8.1 или 8.2**.
Дополнительные расширения не нужны (используются стандартные: json, mbstring — есть по умолчанию).

## Шаг 3. Домен и SSL
1. Привяжите папку к домену `sitevrost.ru` в панели REG.RU.
2. Установите бесплатный SSL-сертификат (Let's Encrypt) в панели.
3. После установки SSL раскомментируйте в `.htaccess` блок принудительного HTTPS
   и строку `Strict-Transport-Security`.

## Шаг 4. Вход в админку
- Адрес: `https://sitevrost.ru/admin`
- Первоначальные данные для входа выдаются владельцу проекта отдельно
  (логин: `admin`). **Сразу после первого входа смените пароль**:
  Админка → «Безопасность» → «Смена пароля».
- Пароль хранится только в виде необратимого хеша в `data/config.php`;
  после 5 неудачных попыток вход блокируется на 15 минут.

## Шаг 5. Почта для заявок
Заявки со всех форм сохраняются в админке (раздел «Заявки») и дублируются письмом
через функцию `mail()` (работает на REG.RU из коробки). Адрес получателя меняется
в админке: «Шапка и футер» → «Почта для заявок» (по умолчанию `sonicsquad@mail.ru`).

## Что где лежит
| Путь | Назначение |
|---|---|
| `index.php`, `engine/` | фронт-контроллер и шаблоны сайта |
| `admin/` | административная панель (TinyMCE, страницы, блог, кейсы, заявки, настройки) |
| `data/*.json` | контент: страницы, статьи, кейсы, заявки, настройки (редактируется из админки) |
| `data/config.php` | хеш пароля администратора (недоступен извне) |
| `upload/` | загруженные из админки изображения (PHP в папке отключён) |
| `assets/` | стили, скрипты, изображения, логотипы |
| `tools/seed.php` | дев-утилита первичного наполнения (закрыта от внешнего доступа) |
| `robots.txt`, `/sitemap.xml` | для поисковых роботов (sitemap.xml генерируется автоматически) |

## Безопасность (уже включено)
- CSRF-токены на всех формах; скрытое поле-ловушка от ботов; лимит заявок с одного IP.
- Служебные папки (`data`, `engine`, `tools`) закрыты через `.htaccess`.
- Заголовки безопасности: X-Content-Type-Options, X-Frame-Options, Referrer-Policy и др.
- Загрузка файлов: только изображения, проверка сигнатуры, ограничение 8 МБ.

## Визуальный редактор
В админке для страниц, статей блога и кейсов подключён **TinyMCE** (загружается с CDN,
нужен интернет в браузере администратора): стили, ссылки с анкором и без, кнопки со
ссылками, таблицы, изображения (загрузка с компьютера), вкладка «Код» и пункт меню
«Вставить HTML-код» — для вставки произвольного HTML в любое место текста.
